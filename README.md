# supersonic-tx

**Cast fuzzy transaction bundles to mislead voyeurs.** `supersonic-tx` buries a user's
real transfer inside a bundle of economically-real, recoverable decoy transfers, so an
on-chain observer — a copy-trader, a clustering model, a forensic analyst — cannot tell
*which* transfer the user actually meant.

Built for the Superteam Brasil **"noise"** bounty (privacy-through-noise tooling for
Solana). Rust end-to-end. MIT.

> **What this is, precisely.** On Solana there is no public mempool and every confirmed
> transaction is public forever, so this tool does **not** hide that a transaction
> happened or who signed it — that is impossible, and pretending otherwise would be a
> lie. It manufactures **intent ambiguity**: the real leg is one of `K` plausible legs,
> and an adversary should do no better than a `1/K` guess at picking it. That claim is
> **measured**, not asserted — see [the proof](#proof).

---

## The idea

Every transfer you make is legible: an observer reads the net balance change and knows
exactly what you did. Adding fake activity doesn't help if the fakes move no value —
they're filtered out in one step by looking at balance deltas. So the decoys here move
**real** value (the tool costs fees to run), but only *your own* funds, to destinations
*you control and can sweep back*. To the outside world it looks like `K` real payments;
to you, `K−1` of them are a parking lot you recover from later.

The hard part is making the real leg statistically invisible among the decoys. That's an
engineering problem with a number attached, and most of this repo is about getting that
number to zero and **proving** it.

Read [`THREAT_MODEL.md`](./THREAT_MODEL.md) for the adversary model and the metric, and
[`ARCHITECTURE.md`](./ARCHITECTURE.md) for how the pieces fit.

## Proof

The adversarial harness runs real classifiers against bundles generated by the real SDK
and reports the attacker's advantage over a random `1/K` guess, on a held-out test split.
The attack suite includes eight fixed heuristics **and a learned logistic-regression
adversary** trained on the train split — the attack a real copy-trader would run. It also
includes `log_median_central` ("pick the most central value"), the attack that broke an
earlier design: decoys were centred on the real amount, making the real leg the most
central value. The generator now uses an **exchangeable construction** — the real amount
is treated as one draw from the bundle's own log-normal, so no amount- or position-based
attack can separate it (see [`THREAT_MODEL.md §3–4`](./THREAT_MODEL.md)).

| K (anonymity set) | random baseline | attacker's best advantage (incl. learned) | verdict |
|---:|---:|---:|:--|
| 2  | 0.500 | **+0.042** | weakest — small residual |
| 4  | 0.250 | **+0.034** | small residual |
| 8  | 0.125 | **+0.014** | indistinguishable |
| 16 | 0.062 | **+0.011** | indistinguishable |

*(seed 1, 8000 bundles per split; reproduce with `cargo run -p supersonic-harness
--release -- --n 8000 --seed 1`.)*

For **`K ≥ 8`** even the learned adversary does no better than the `1/K` baseline. `K = 4`
retains a small residual (~14% of baseline) and `K = 2` is weakest (boundary effects in a
tiny anonymity set), so **use `K ≥ 8`** for a strong guarantee. The full evidence,
including live devnet transactions, is in [`PROOF.md`](./PROOF.md).

## Install

Requires the Solana toolchain (Agave CLI + Anchor 0.31) and Rust.

```bash
git clone <this repo> && cd supersonic-tx
anchor build                       # build the on-chain program
cargo build --release              # build the SDK, CLI, and harness
```

The CLI binary is `target/release/supersonic`.

## Quickstart

```bash
# 1. Dry-run: see the bundle that would be cast (nothing sent)
supersonic plan --to <REAL_PAYEE> --amount 0.02 --k 8

# 2. Cast it: your 0.02 SOL payment, hidden among 7 recoverable decoys
supersonic send --to <REAL_PAYEE> --amount 0.02 --k 8

# 3. Later, sweep the decoy funds back to your wallet
supersonic recover --bundle-id <ID> --k 8

# 4. Review what you've cast
supersonic inspect
```

Defaults target devnet. The recovery secret is derived from your wallet key, so the same
wallet always recovers its own decoys — nothing extra to back up.

## Composability

Other tools "cast through" `supersonic-tx` two ways:

- **On-chain:** route through the stable program id via the published Anchor IDL.
- **In Rust:** call `plan_bundle` / `build_instruction` from `supersonic-sdk`. A
  companion `account-cooker` can both generate real intents to route here *and* host
  decoy destinations so they stay live — which mitigates the consolidation tell below.

## Honest limitations

- **Costs money.** Real decoys mean real fees + parked principal. Inherent to defeating
  the balance-delta filter, not a bug.
- **Consolidation tell (mitigated, not eliminated).** Sweeping all decoys back at once
  re-links them (`THREAT_MODEL §4.6`). `recover --disperse` sends each decoy to its own
  distinct sink in a separate transaction, removing the star pattern; full unlinkability
  across time still benefits from keeping decoys live (an `account-cooker`). The harness
  reports the naive worst case explicitly rather than hiding it.
- **Per-bundle metric.** The `1/K` guarantee is per bundle; repeated use across many
  bundles leaks a behavioral prior. Stated, not solved.
- **Destination-history channel** is out of scope for the harness (it holds destinations
  constant); a real payee with on-chain history is a separate signal, addressed
  operationally by pre-warming decoy addresses.
- **Devnet-validated.** Deployed and exercised on devnet; not audited for mainnet.
- **Tooling note:** `cargo clippy` currently ICEs on the SDK crate (a clippy×solana-sdk
  toolchain bug, reproduced on clippy 0.1.94 and 0.1.96); `cargo build` and `cargo test`
  are clean.
